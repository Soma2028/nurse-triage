# キャラクターの画像

ここに次の3枚を置くと、ビルド時に自動で読み込まれて仮の SVG と差し替わります。
1枚でも置けば、その表情だけ差し替わります（ないものは仮の SVG のまま）。

| ファイル名   | 表情     | 出る場面                                             |
| ------------ | -------- | ---------------------------------------------------- |
| `normal.png` | ふつう   | ふだんの日                                           |
| `worry.png`  | 心配     | 期限切れ・時間不足・24時間以内・追い込まれているとき |
| `happy.png`  | うれしい | 課題がぜんぶ片づいた・休みの日                       |

- 透過 PNG、正方形（512×512px 推奨）
- 生成り色（`#fbf8f3`）の背景に乗るので、背景は透過にしてください
