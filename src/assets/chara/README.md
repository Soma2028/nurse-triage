# キャラクターの画像

ここに次の3枚を置くと、ビルド時に自動で読み込まれて仮の SVG と差し替わります。
1枚でも置けば、その表情だけ差し替わります（ないものは仮の SVG のまま）。

| ファイル名   | 表情     | 出る場面                                             |
| ------------ | -------- | ---------------------------------------------------- |
| `normal.png` | ふつう   | ふだんの日                                           |
| `worry.png`  | 心配     | 締切過ぎ・時間不足・24時間以内・追い込まれているとき |
| `happy.png`  | うれしい | 課題がぜんぶ片づいた・休みの日                       |

- 透過 PNG、正方形（512×512px 推奨）
- 生成り色（`#fbf8f3`）の背景に乗るので、背景は透過にしてください

## アプリのアイコン

ブラウザのタブのアイコン（`public/favicon.svg`）と、iPhone のホーム画面のアイコン（`public/apple-touch-icon.png`、180×180px、生成り色の背景）は、仮キャラクターの「ふつうの顔」で作っています。
`normal.png` を用意したら、この2つも同じ絵に差し替えてください（ホーム画面のアイコンは透過にせず、背景を生成り色 `#fbf8f3` で塗ってください。iOS は透過部分を黒く塗るため）。
