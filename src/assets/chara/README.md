# キャラクターの画像

ナースキャップのフクロウ。ユーザーが用意した絵（8つの表情）から、背景を透明にして切り出したもの。
ここに置いた `normal.png`・`worry.png`・`happy.png` が、ビルド時に自動で読み込まれる（ないものは `Chara.tsx` の仮の SVG）。

| ファイル名   | 表情               | 出る場面                                                           |
| ------------ | ------------------ | ------------------------------------------------------------------ |
| `normal.png` | 笑顔（にこにこ）   | ふだんのホーム                                                     |
| `worry.png`  | 困り顔（うーん）   | 締切過ぎ・赤の課題があるときのホーム                               |
| `happy.png`  | 喜び（やったー！） | 今日のぶんが終わった・課題がぜんぶ片づいた・完了したときのトースト |

- 透過 PNG、正方形 256×256px（いちばん大きく出すのが 72px なので、iPhone の3倍の画面でも足りる大きさ）
- どの表情も同じ大きさ・足もとの位置にそろえてある（表情が変わっても、フクロウが動かないように）

## まだ使っていない表情（`extra/`）

`extra/` に、ほかの表情も 512×512px で取ってある（アプリには読み込まれない）。
応援（`cheer`）・驚き（`idea`）・疲れ（`tired`）・感謝（`thanks`）・焦り（`panic`）と、上の3つの元の大きさのもの。
使うときは 256px に縮めてこのフォルダに置き、`Chara.tsx` の `Mood` に足す。

## アプリのアイコン

`public/` の `apple-touch-icon.png`（180px）・`icon-192.png`・`icon-512.png`・`icon-maskable-512.png`（丸く切られても欠けないよう小さめ）・`favicon.png`（ブラウザのタブ、64px・透過）は、笑顔の絵から作っている。
ホーム画面のアイコンは透過にせず、生成り色（`#fbf8f3`）で塗る（iOS は透過部分を黒く塗るため）。
